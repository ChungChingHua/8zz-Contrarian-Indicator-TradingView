# 離線語意與證據檢查（2026-11-07）

這輪沒有生成、模型／額度查詢、圖片下載，也沒有讀取 API 金鑰。`.tech/v1` 供應商設定保留；一般 pause=true、一次性入口、排程與 Pages 仍停用，PR 未合併。**技術 smoke 通過不代表品質通過，也不授權小批或 659 篇處理。**

## 已實作

`scripts/semantic_gate.py` 對模型輸出做離線、保守的一致性檢查，保留 `model_candidate` 原答案，正式決策另存 `semantic_check`（版本、問題代碼、證據）。輸出固定 JSON schema 維持原欄位；更新的 prompt 版本 `contrarian-evidence-v3` 尚未送至服務。既有回應仍標原先的 prompt 版本，沒有假稱已用新 prompt 判讀。

- 投資相關=false 卻有方向、理由明說沒有投資證據卻相關=true、理由不確定卻 clear=true／有方向、方向與恐慌／亢奮理由不符、原文或理由出現混合情緒，轉 review、方向0，不產生訊號。
- 非零方向必須有原文的投資情境與相符情緒線索；文字與已驗證圖片缺乏標的證據時不能發訊號。沒有明確買賣宣告不是拒絕情緒訊號的理由；單純買賣／持有行為也不是情緒訊號。
- target、ticker 分別驗證：必須逐字出現在本人原文，或有綁定實際下載圖片 SHA-256 的人工核對文字。2330 不會自動補成2330.TW，發哥不會自動補成聯發科，0050 不會匹配00500。ticker 無證據則清空；target 無證據則兩者清空。確定無關投資也清空標的。
- 平台 `ocrText`、模型 `images_reviewed=true`、模型回報的圖片描述，都不等於人工已核實標的。**沒有人工核圖資料時，純圖片標的不會自動採用。**
- 無第三方引用結構卻輸出 quoted_summary，標記引用界線待確認，避免把本人原文或「市場跟我說」修辭當成第三方文章。
- Pine 生成也會重新跑同一離線檢查，不能繞過檢查直接採用舊的 done 快取。歷史 Pine 事件區塊不受新 gate 追溯改寫。

這是可審查的規則檢查，**不是通用語意理解或正確性證明**。它能攔已知顯式矛盾與無證據標的，可能保守地多攔截合法語句，亦不能完全辨別反諷、否定範圍、同文多標的、引述或標的與情緒的因果歸屬。逐字提及只是必要條件，不能保證作者真的對該標的表態；圖片持倉也不等於對每檔持股表態。這些仍須以人工確認的樣本評估，不能因離線測試通過就宣稱判讀品質合格。

## 狀態、重試與費用

| status | decision_type | 意義 | 一般流程自動再次列為 API 候選 |
| --- | --- | --- | --- |
| pending | unprocessed | 尚未判讀 | 是，僅在另行授權且解除暫停後首次處理 |
| done | signal | 通過必要證據與一致性檢查 | 否 |
| no_signal | unrelated / neutral | 確定無關／中性，方向0 | 否 |
| review | insufficient_information | 資訊不足／輸入須人工補正，方向0 | 否 |
| review | semantic_conflict | 欄位或證據矛盾，方向0 | 否 |
| retry | technical_failure | API／傳輸／輸出格式等技術失敗，方向0 | 是，仍受暫停、未來授權與既有上限控制 |

穩定的輸入問題（影片／未知附件、過大／不允許格式或網址、缺圖、上下文太長、代理傳輸需審查）會要求人工補正，不因重跑就再付費。逾時、API 錯誤或回應無法解析等仍保留技術失敗及安全錯誤資訊。這輪沒有啟用任何重試或線上功能。內容編輯重新匯入會依原有 content_hash 邏輯失效舊答案；人工重送必須另行授權，不能為換一個答案自動重送。

## 人工圖片證據的本地格式

目前沒有已核實圖片標籤，`data/verified_image_evidence.json` 不存在時視為空集合。未來由人工核對原始圖片與雜湊後，才可在 PR 加入以下格式；圖片／模型文字不能自行寫入此檔，分類流程也不會替它建立或批准記錄。

```json
{
  "facebook:POST_ID": [
    {
      "reviewed": true,
      "reviewer": "實際核對者",
      "verified_at": "實際核對時間",
      "sha256": "實際供應圖片的64位SHA256",
      "observed_text": "人工確認圖片中實際可見的文字"
    }
  ]
}
```

必須與該次下載 `image_evidence.sha256` 相同；平台 OCR 不可直接標為 reviewed=true。此資料只能證明某段文字出現在該圖，仍不證明作者對每個標的的立場。不要加入帶簽名 CDN URL、憑證或日後行情。
