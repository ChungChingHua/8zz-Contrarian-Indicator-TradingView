# Apify 現行限制政策（2026-11-14）

依使用者最新指示，PR #1 移除程式內「每次 US$0.10」與「每月 70 次 Actor 啟動」兩項限制。此文件取代舊階段文件對這兩項現行限制的描述；歷史執行帳本與當時授權數值保留原樣，不回寫或歸零。

## 實作範圍

- 所有 Actor 啟動入口共用 `scripts/apify_run_policy.py`，不再傳送 `maxTotalChargeUsd`。涵蓋一般 social 抓取、live 增量、歷史增量、歷史媒體補抓、媒體修復及獨立成本實驗入口。
- 移除啟動前的每月 70 次檢查；移除 live_settings 中的兩個過時設定。
- 不再因成本達到原本 US$0.10 就判定截斷，也不要求服務回傳 US$0.10 上限作為啟動成功條件。
- 新預留紀錄的費用上限欄位為 null，表示程式未設定美元上限，不代表零費用。共用帳本仍在啟動前保存預留次數；run ID、費用與未知提交仍保存。
- 費用報告讀取帳本的原始限制資訊，避免把舊實驗的授權上限當成目前程式設定。

## 保留的行為

- 來源 ID／跨平台內容去重、已保存資料集重用、媒體快取驗證；不因移除限制而重抓整段歷史。
- 各來源從上次成功截止時間接續，保留重疊；結果達筆數限制、結構異常或服務明確回報截斷時，不推進成功游標。
- HTTP 認證／存取／額度拒絕、Actor 失敗與狀態不明仍保存並停止；可能已送出的請求不自動重送。
- 每 run 的 180 秒、512 MB、maxItems 與禁止自動重啟保留。獨立實驗的單次操作啟動數量範圍也保留，既有實驗帳本不會因這次修改重新執行。
- Apify 若回傳實際生效的費用限制且成本已達該限制，仍視為可能截斷；不以固定 US$0.10 推測。平台帳戶額度、Actor 定價／自身限制未被更改，不自動儲值。
- AI 次數限制、免費模型設定、Secrets 隔離、原作者判讀、事件與指標／策略 Pine 皆未變更。

## 本次驗證

256 項離線 unittest 通過，涵蓋超過原本每月限制仍記帳、沒有送出費用上限參數、超過原本單次費用仍可完成、服務實際截斷時保留游標、401／402／403 只送一次、失敗／未知不重送，以及既有去重與資料隔離。

完整指標與策略的 380 筆事件及檔案內容保持相同；此次不新增歷史資料或判讀結果。未進行新的 TradingView 編譯驗證。

本次沒有啟動 Apify／AI、發送 Telegram、啟用排程、發布網站或合併 PR。新政策尚未以付費線上 run 驗證。移除程式上限不代表 Apify 帳戶額度已恢復，也不保證每次或每月費用。
